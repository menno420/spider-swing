# Environment theme source record

> **Status:** `prototype-source-record`

These four prototype textures were generated with OpenAI image generation on
2026-07-29, then mechanically resized to 384×384 WebP runtime assets at quality
52 with metadata stripped. The greenhouse source was center-cropped to a square
before resizing. No third-party source image was used.

The original generated files are intentionally not duplicated in Git. This
prompt-and-hash record is the editable regeneration source while the compressed
runtime tiles are the reviewable game inputs.
