# Zones 3–8 finished-art source record

> **Status:** `candidate-production-source-record`

Thirteen original assets were generated by OpenAI image generation on
2026-07-31. The only visual context consulted was Spider Swing's own committed
Ancient Forest runtime art, used as an internal finish/material reference. No
external image, museum object, paper figure, stock asset, Wikimedia file, or
other third-party reference was consulted or copied; therefore there is no
reference URL, creator attribution, or external licence to record.

Every source was generated on a flat chroma field, keyed to alpha at its full
generation resolution with the image-generation skill's
`remove_chroma_key.py`, then reduced with a Lanczos filter. The runtime matte
was despilled again after resize. `tools/zone_art_audit.py` inspects partial
alpha at keyed-source, runtime, and 25% gameplay scale. The committed audit
reports zero visible magenta fringe in all three states. Full source canvases
are represented by SHA-256 rather than committed, matching the existing forest
art policy; Godot imports only inspected runtime files.

## Shared generation direction

- painterly naturalistic fantasy finish compatible with the existing game;
- large structural silhouettes readable at 760 px lead and at 25% scale;
- subdued background detail; valid anchors, lethal rims, and flies remain the
  highest-contrast elements;
- no text, UI, player, fly, watermark, frame, or raster-defined collision;
- flat `#ff00ff`-family chroma field, later keyed to alpha;
- seam-aware compositions mirrored on alternating tiles by `SwingLabView`.
