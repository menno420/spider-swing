# Generated game-audio source

> **Status:** `source-record`

Spider Swing's gameplay samples and two-stem background score are generated by
`tools/generate_audio_samples.py`. The generator uses elementary oscillators,
Karplus–Strong plucks, deterministic seeded noise, filters, envelopes, and
delays. It consumes no recordings, sample libraries, reference audio, web
downloads, or third-party material.

## Production contract

- Runtime format: mono 44.1 kHz, 16-bit PCM WAV. Mono keeps memory and APK cost
  low; these non-positional interface/gameplay cues do not benefit from baked
  stereo.
- Every transient ends below 0 dBFS and includes a 3 ms edge fade. The generated
  manifest records duration, peak, RMS, SHA-256, event mapping, and loop state.
- Web attach, release, Burst, Dive, and fly catch have round-robin variants.
  Presentation applies event-specific cooldowns; authoritative simulation never
  chooses or times a sound.
- `reel-loop.wav` is a mathematically periodic 0.5-second loop made only from
  integer-Hz components. Runtime owns loop start/stop from snapshots.
- `haunted-silk-bed.wav` and `haunted-chase-pulse.wav` are synchronized
  32-second loops. Whole-loop oscillators, circular harmonic crossfades, and
  wrapped bell tails keep their boundaries continuous without fading the score
  to silence. Presentation owns the tension-stem mix.
- Regenerate with `python3 tools/generate_audio_samples.py`; prove exact
  reproducibility with `python3 tools/generate_audio_samples.py --check`.
