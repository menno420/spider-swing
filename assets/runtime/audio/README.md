# Runtime game audio

> **Status:** `runtime-assets`

Twenty-five original procedural SFX cover web attach/release, Reel
start/loop/empty, Burst, Dive, fly and boost pickup, invalid actions, rescue,
death, Buckler bounce, and five later-zone warning cues. Two additional
32-second stems form the haunted background score: a persistent silk/forest bed
and a pressure-responsive chase pulse.

`audio-sample-manifest.json` is authoritative for format, duration, headroom,
loop state, event mapping, provenance, and SHA-256. Authoring and regeneration
instructions live in `assets/source/audio/README.md`.

These are playtest samples, not locked final mixes. Device feedback should judge
whether each event reads through a phone speaker, whether any loop fatigues,
whether the score sits behind SFX, and whether later-zone warnings lead the
hazard without becoming distracting.
